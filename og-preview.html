Cómo guardarla como imagen PNG

  1. Chrome / Edge: F12 (DevTools) → ícono de móvil arriba (Toggle device toolbar) → escribe 1200 × 630 en el tamaño → Cmd/Ctrl+Shift+P → escribe "screenshot" → click "Capture node screenshot" seleccionando el rectángulo crema.
  2. Más fácil: instala la extensión "GoFullPage" de Chrome → toma screenshot completo → recorta a 1200×630 con cualquier editor.
  3. Mac: también funciona Cmd+Shift+4 y arrastrar sobre el rectángulo crema (no incluye el fondo gris ni este texto).
  4. Guarda la imagen como og-image.png y avísame para subirla y conectarla.
